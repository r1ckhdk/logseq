- [[RNP - Arquitetura e Protocolos de Rede TCP-IP]]
	- **Módulo 6**
		- Protocolos da camada de rede
			- Fragmentação
				- Processo de divisão de datagramas em pequenas partes, denominadas **fragmentos**
				- Fragmentos e datagramas possuem formatos idênticos
				- Datagrama original e seus respectivos fragmentos possuem cabeçalhos similares
				- Fragmentos podem ser refragmentados
			- Remontagem
				- Processo de recuperação do datagrama original a partir dos seus fragmentos
				- É realizadas apenas no destino final dos fragmentos
				- O datagrama original não pode ser remontado quando algum fragmento atras ou é perdido
				- Identification
					- Número int que identifica o datagrama original
					- Copiado para cada fragmento
				- Fragment Offset
					- Deslocamento dos dados do gramento em relação ao datagrama original
					- Indicado em unidades de 8 bytes
				- Flags
					- Conjunto de três bits que auxiliam o processo de fragmentação
					- Apenas dois bits são usados
					- Do not fragment
						- Desabilita a fragmentação
					- More fragments
						- Indica se o fragmento transporta dados do fim do datagrama original
			- Protocolo ICMP
				- Permite que estações e roteadores troquem informações de erro e controle
				- Define diversos tipos de mensagens
				- Sinaliza algumas situações anormais
				- Principais mensagens
					- Echo request / reply
						- Testam se um destino está operacional
					- Destination Host Unreachable
				- Comando ping
					- Verificação de conectividade
					- Envia um echo request para o destino
					- Destino responde com um pacote echo reply
					- É informado o Round Trip Time (RTT) - tempo de ida e volta
				- Comando traceroute (Linux)
					- Mostra o caminho do pacote até o destino
					- Envia datagramas UDP para o destino
					- Inicia com TTL=1 e vai incrementando até o destino
					- Envia 3 datagramas para cada hop
					- Cada roteador (hop) no caminho subtrai 1 do TTL
