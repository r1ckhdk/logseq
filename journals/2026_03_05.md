- [[RNP - Administração de Sistemas Linux]]
	- **Módulo 9 - Segurança básica e procedimentos operacionais**
		- Segurança básica
			- Desabilitar serviços desnecessários
			- Utilizaar ferramentas do tipo scanner de vulnerabilidades
				- npam, openVAS
			- Implementar serviços com suporte a criptografia
				- SSH, SFTP, HTTPS
			- Utilizar firewall para controlar o acesso aos serviços
			- Implementar um serviço de proxy para controlar o acesso a Internet
		- Ambiente enjaulado
			- chroot --> containers
				- Quando um serviço que está sendo executado de forma enjaulada é comprometido, o restante do sistema não é comprometido
		- Analisadores de senhas
			- Problema das senhas fracas
			- Conscientizar os usuários
			- Treinamentos sobre a importância de uma senha segura
		- Contas compartilhadas
			- Utilizadas por diversos usuários
			- Ajudam a poupar tempo e evitam a criação de contas desnecessárias
			- Uso não recomendado
			- Dificulta a identificação do autor das ações
			- O mesmo se aplica à conta root
			- Desabilitar o uso do comando su
		- Atualização de software
			- Manter os softwares sempre atualizados
			- Pode ser feito de forma manual ou automática
			- Ficar atento aos alertas de vulnerabilidades
			- Fazer parte de listas de discussão
			- Gerenciador de pacotes
				- **YUM: Yellowdog Updater, Modified**
					- RHEL, Fedora, CentOS
					- Resolve problemas com dependências, instalando-as automaticamente
					- Utiliza repositórios para fazer o download dos pacotes
					- Possui interfaces gráficas e uma interface de texto baseada no comando YUM
				- **APT: Advanced Packaging Tool**
					- Debian-based
					- Resolve problemas com dependências, instalando-as automaticamente
					- Utiliza repositórios para fazer o download dos pacotes
		- Monitoramento
			- Arquivos de log
			- Contas de usuários
			- Sistema de arquivos
