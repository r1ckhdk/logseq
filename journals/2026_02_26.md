	- **Módulo 6 - Sistema de impressão**
		- Histórico
			- Baseava-se em dois sistemas
				- **Line Printer Daemon (LPD) - BSD**
				- **Line Printer System - System V**
			- Evolução dos softwares não acompanhavam o hardware
			- Busca por uma interface padrão de impressão
				- **IPP do IETF**
		- **CUPS**
			- Surge como alternativa às implementações do protocolo LPD
			- Servidor **padrão** na maiioria das distros
			- Utiliza protocolo IPP
			- Vantagens em relação às LPD based
				- Escalonador baseado em servidor HTTP 1.1
				- Interface web para adm e config
				- Maior número de opções de impressão
				- Controle de acesso apurado
				- Suporte à criptografia e proxy
				- Facilidade na config para clientes Windows

	- **Módulo 7 - Backups**
		- Política de backup
			- Deve ser baseada na frequência de modificação dos arquivos e no grau de importância de cada um
		- Três tipos de backup
			- **Completo**
			  logseq.order-list-type:: number
				- Todos os arquivos de interesse são copiados para a mídia de destino
				  logseq.order-list-type:: number
				- Consome grande quantidade de tempo para ser realizado
				  logseq.order-list-type:: number
			- **Diferencial**
			  logseq.order-list-type:: number
				- Apenas os arquivos alterados a partir do último backup completo serão copiados para a mídia de destino
				  logseq.order-list-type:: number
				- O processo de recuperação dos dados é um pouco mais complexo pois serão necessárias, pelo menos, duas mídias: a última do backup completo e a do último backup diferencial
				  logseq.order-list-type:: number
			- **Incremental**
			  logseq.order-list-type:: number
				- Só é armazenado o conteúdo que foi alterado após a realização do último backup, independente de seu tipo
				  logseq.order-list-type:: number
				- Apesar de ser o tipo mais rápido, dtende a deixar o processo de recuperação de arquivos mais complexo
				  logseq.order-list-type:: number
		- **Mídias de backup**
			- Fitas magnéticas
				- Digital Linear Tape (DLT)
					- Desenvolvida pela DEC em 1984
					- Capacidade de armazenamento nativa de até 800 GB e 1.6 TB compactado com taxa de transmissão de 60 MB/s e 120 MB/s compactado (modelo: DLT S4)
					- Durabilidade de até 30 anos
				- Linear Tape Open (LTO)
					- Tecnologia de formato aberto
					- Capacidade de até 12 TB e 30 TB compactado com taxa de transmissão de até 750 MB/s
					- Durabilitade de 15 a 30 anos
			- Discos magnéticos
				- Velocidade de acesso está diretamente relacionada a interface de comunicação e a quantidade de rotações por minuto (rpm)
				- Ótimo custo benefício
				- SATA I - 150MB/s
				  SATA II - 300MB/s
				  SATA III - 600MB/s
			- Memórias Flash
				- Interface PCI Express 3.0 podem chegar a, teoricos, 15,76 GB/s
				- SSDs recentes conseguem atingir uma taxa de leitura de 3,5GB/s utilizando o padrão NVMe
			- **Storage**
				- Hardware para armazenamento de dados
				- Alto desempenho no acesso aos dados
				- Escalabilidade
				- Tecnologias de transferência de dados (SCSI, Fibre Channel, SAS e SATA)
				- Tipos de conexão (DAS, NAS, SAN e iSCSI)
				- Provê redundância de dados (RAID)
			- **Armazenamento na Nuvem**
				- Utiliza internet para transmitir os arquivos
				- Necessita de empresa especializada para prestação de serviço
				- Custo inicial é relativamente baixo
				- Deve-se certificar que os dados são armazenados de forma criptografada pela prestadora do serviço
		- **Políticas de backup**
			- O que?
				- Identificação de quais informações precisam fazer parte da rotina de backup
					- Ex.: dados de usuários, bancos de dados, relatórios, arquivos de configuração de serviços, entre outros
			- Quando?
				- Definição da frequência que cada informação deverá ser armazenada
				- Cada tipo de dado pode ter uma necessidade diferente, por conseguinte, diferentes critérios para a realização do backup
			- Onde?
				- Definição de qual é a melhor mídia para cada tipo de backup
				- O adm deve conhecer as vantagens e desvantagens das mídias de armazenamento disponíveis para escolher a opção adequada para cada necessidade
			- Como?
				- Será automatizado ou manual?
			- Por quanto tempo?
				- Definição do período de retenção de cada tipo de backup
			- *Outros fatores*
				- Criticidade
				- Criptografia
				- Janela de backup
				- Compactação
				- Dispositivos
				- Redundância
				- MTBF (Mean Time Between Failure)
		- **Ferramentas**
			- Bacula
				- Formado por um conjunto de módulos que podem ser executados em uma única máquina ou em máquinas diferentes
				- Gerenciamento centralizado
			- Amanda
				- Arquitetura cliente/servidor
				- Utiliza aplicativos nativos do Linux (dump, tar etc.)
				- Suporte a diversos tipos de mídias
